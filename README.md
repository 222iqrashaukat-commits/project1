# Plant Care Website

A responsive and user-friendly plant care website designed to help users explore plants, learn essential care tips, and manage plant-care schedules.

## Features

* Responsive design for desktop, tablet, and mobile
* Plant information and care details
* Plant-care tips section
* Plant-care schedule
* Contact form
* Light and dark mode
* Clean and modern user interface

## Technologies

* HTML5
* CSS3
* JavaScript



## Getting Started

### Clone the repository

git clone https://github.com/YOUR-USERNAME/plant-care-website.git

### Run the project

Open the project in Visual Studio Code and run `index.html` in a web browser.

You can also use the Live Server extension for development.

## Responsive Design

The website adapts its layout for different screen sizes using CSS media queries, including desktop, tablet, and mobile layouts.
